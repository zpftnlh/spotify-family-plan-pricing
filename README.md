## 车位制和升级到自己账号，操作差别比价差更值得看

### 车位制：你的账号加进别人的家庭组

流程不长。拿到家庭组邀请链接，点接受，账号就升级成 Premium，中途可能要求填一个与主账号相同的地址信息。

几个容易踩的点：

- 一个账号同一时间只能待在一个家庭组里。之前加过别人的组，先在「账号设置 → 家庭 → 退出家庭组」退掉。退出后一般不需要等冷却期，但系统延迟可能拖几小时到一天。
- Premium 还没到期也能加入新组，不过原来的订阅会继续扣费到到期日，等于同一段时间付两份钱。要么先取消个人订阅，要么等临近到期再进组。
- 数据这块是车位制最实在的好处：歌单、收藏、听歌记录、年度总结全都留在你自己的账号里，只是订阅类型变了。

### 升级到自己账号：不换号，但可能要交一次邮箱验证码

有的平台直接把你的账号升成 Premium，续费还在原账号上，不用迁移任何东西。要求提供的东西通常是 Spotify 注册邮箱加一次邮箱验证码，验证码用完即失效。也有平台会要账号密码，这里差别很大——验证码是一次性授权，密码是长期权限。

### 要不要自备账号？看模式，别信统一答案

网上很多攻略在这一点上自相矛盾：一会儿说必须自己注册一个免费账号，一会儿说平台会给你现成账号、直接登录就行。两种说法各自对应一种模式。

买家庭组车位的，必须有账号，而且要能退出原来的家庭组。买平台现成账号的，不用注册，代价是那个账号里没有你的历史，歌单只能靠导出功能搬过去，年度总结也归零。

用别人给的账号还有一套别人定的规矩：不改密码、不登出其他设备。这些通常在你付款时会告知，违反了大概率算你自己违约。

## 选哪个区，以及两个真实的体验短板

台湾区是目前合租里最常见的选择，价格相对低，车位也好找。Spotify 官方支持无损的地区名单里包括台湾、香港、新加坡、印度、美国、日本等一大批市场。印度区经常被拿来说便宜，核心功能确实一致，差别在默认语言、初始推荐更偏印度本土音乐，以及支付方式。合租用户的区域通常由平台或车主决定，你自己挑的余地不大。

两个短板得提前知道：

**无损不等于 HiRes。** Spotify 标称的最高音质是 24-bit/44.1 kHz，绝大部分歌曲都有无损版本，但不支持 HiRes，而 Apple Music、Tidal 以及国内几家流媒体都已经支持了。对绝大多数耳机和耳朵来说够用，对追求高解析格式的人来说是硬伤。

**歌词是主要槽点。** 相比同属海外的 Apple Music，Spotify 少了歌词翻译功能，而且相当多歌曲干脆没有歌词。iOS 上可以用 DualSubs 之类的工具增强，Windows 上 Spicetify 的插件市场里有对应插件。

另外，音质档位要自己去设置里调：自动、低 24kbps、正常 96kbps、高 160kbps、非常高 320kbps，其中「非常高」只有 Premium 能用。合租账号都是 Premium，但默认不一定给你开到最高。WiFi 和蜂窝流量可以分开设。

至于国内直连，有用户反馈用 dot.pub 做 DNS 时，移动和联通听无损比较流畅但视频会卡，换运营商 DNS 就都卡。这个说法本人也标注了未证实，别当结论用。
